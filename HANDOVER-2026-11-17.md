## Gotchas met today

- After a PC or session restart Docker Desktop fails on stale socket files: stop docker processes, rename `%LOCALAPPDATA%\Docker\run` and `%LOCALAPPDATA%\docker-secrets-engine` to `*.stale-<time>`, delete `%LOCALAPPDATA%\Docker\backend.error.json`, relaunch, then `docker start huemen_db`.
- An orphan `next dev` can hold port 3120 and hang: kill the listener on 3120 (and node processes whose command line has huemen-studio + next) before starting the preview server, otherwise it moves to 3121 and dies.
- Git Bash `curl` failed for every HTTPS URL after a restart (exit 43); use node fetch or PowerShell.
- Git Bash heredocs eat backslashes: edit source with the Edit/Write tools, never sed/python one-liners (it wrote a real newline and a NUL byte into source twice today).
- Built-in browser: a hidden pane does not draw; bring the tab forward (tabs_select / show the pane) for screenshots and clicks.
